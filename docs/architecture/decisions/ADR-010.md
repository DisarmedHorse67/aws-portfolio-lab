# ADR-010: Public repository under the MIT license

Status: accepted
Date: 2026-10-29

Context: The repository is the portfolio, so people outside the project
must be able to read it. A repository with no license is not legally
reusable by others.

Options:
- Private repository: no exposure risk; nobody can review the work.
- Public with MIT: simple, permissive; no explicit patent grant.
- Public with Apache-2.0: permissive with a patent grant; longer terms.

Decision: Public repository named `aws-portfolio-lab` under the MIT
license, public from the first commit.

Consequences:
- Risk: everything committed is visible, so secrets are blocked by
  gitleaks, GitHub secret scanning and `.gitignore`, and account IDs,
  emails and ARNs are redacted before publishing.
- Third-party material: themes and tools keep their own licenses.
- History: public commit history shows the work was done step by step.
