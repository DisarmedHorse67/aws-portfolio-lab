# ADR-007: Build the site with Hugo

Status: proposed
Date: 2026-10-29

Context: The portfolio is mostly written content (about, projects,
write-ups) and must be cheap to host and easy to keep accessible.

Options:
- Hugo: a single program, fast builds, Markdown content, built-in
  multilingual support; its template language takes time to learn.
- Astro: component-based and flexible; needs Node tooling and more
  maintenance.
- Hand-written HTML: no tools; no Markdown, templates or language support.

Decision: Use Hugo. It produces plain files that S3 and CloudFront can
serve, reuses the Markdown I write for the docs, and supports the planned
Spanish pages.

Consequences:
- Cost: free; hosting stays within a few cents.
- Learning: the template language is new, accepted as part of the project.
- Accessibility: the theme must pass the accessibility checks in a future
  phase before I rely on it.
- Tooling: the Hugo version is pinned in the dev container and pipeline.
